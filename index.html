FAQ

Before you start

How do I download Nocturne?

Join our Discord server for download access and setup information.

Is this the actual menu?

This is an interactive browser preview of the Nocturne menu. Its controls demonstrate the interface and do not connect to the application.

How do I open the menu?

Press L while Nocturne is running.

Can I save my settings?

Yes. Use the Config tab to save and load your configuration profiles.

Which systems are supported?

Check the current requirements in our Discord before downloading. Supported systems and application versions are listed with the latest release.

Where are the installation instructions?

The current setup instructions are shared with the download in our Discord. Follow the instructions for the version you download.

Where do I get updates?

Join Discord for release announcements and the latest download. Check the release notes for changes and requirements.

Does this preview save my settings?

The Config tab can save preview profiles in this browser. These profiles stay on this device and are separate from your application settings.
